# EnrollMate Frontend

The React application powering EnrollMate. See the [root README](../README.md) for full project documentation.

## Quick Start

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`.

## Scripts

| Script | Description |
|--------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## Tech Stack

React 19, Vite 7, Tailwind CSS 4, Zustand 5, React Router DOM 6, Framer Motion, jsPDF + html2canvas.
